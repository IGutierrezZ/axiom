El servidor de Axiom no está en marcha

Esta ventana muestra el panel que sirve axiom en este equipo (http://127.0.0.1:47700). La aplicación instalada no puede arrancarlo por sí misma: hazlo de una de estas formas.

  1. Abre el acceso directo Axiom del menú Inicio, o ejecuta en una consola:

    axiom ui --detach

  2. En Windows, si instalaste Axiom con su instalador, relanza la tarea que lo arranca al iniciar sesión:

    Start-ScheduledTask -TaskName Axiom

No uses axiom ui sin --detach: el servidor quedaría atado a esa consola y se detendría al cerrarla.

Comprobando el servidor cada pocos segundos. La página se recargará sola cuando responda.
